# Data

## Source dataset (real-data mode)
Brazilian E-Commerce Public Dataset by Olist (Kaggle):
https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce

- ~100k orders (2016–2018), relational tables: orders, order items, customers,
  sellers, products, geolocation, payments, reviews.
- License/terms: see the Kaggle dataset page. Download requires a Kaggle account;
  redistribution terms apply — therefore **do not commit raw CSVs** (`data/raw/`
  and `data/processed/` are gitignored).

### How to enable real-data mode
1. Download the dataset from Kaggle (web UI or `kaggle datasets download
   olistbr/brazilian-ecommerce -p data/raw --unzip` with Kaggle API credentials).
2. Place these CSVs in `data/raw/`:
   `olist_orders_dataset.csv`, `olist_order_items_dataset.csv`,
   `olist_customers_dataset.csv`, `olist_sellers_dataset.csv`,
   `olist_products_dataset.csv`, `product_category_name_translation.csv`,
   `olist_geolocation_dataset.csv` (optional extras ignored).
3. Run: `python -m supply_chain_lab.pipeline --mode real`

## Synthetic fixtures (demo mode)
`data/fixtures/` contains small SYNTHETIC Olist-like CSVs generated by
`src/supply_chain_lab/make_fixtures.py` (deterministic seed). They exist so tests
and the demo pipeline run without credentials. **Fixture outputs are technical
demonstrations only — never present them as business findings.**
